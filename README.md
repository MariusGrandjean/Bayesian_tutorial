# Bayesian_ressources #

This repository is intended to provide ressources to make bayesian analysis easier.

It is designed to assist with Bayesian analysis using the excellent brms package. While not exhaustive, it aims to help you select appropriate priors and distributions for use with brms, as well as guide you through a basic data analysis pipeline. It should be viewed as a foundational tool to support your analysis, rather than a complete guide.


In the future, we aim to make the implementation of bayesian factor design analysis (BFDA) more intuitive. We are currently writing a document to explain how it could be use for power analyses when you want to measure an interaction effect.
